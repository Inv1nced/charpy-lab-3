# Лаба 3 · Ударная вязкость

Учебный сайт по испытанию Шарпи, обработке результатов и подготовке к защите. Сайт работает в браузере без установки. Прогресс по карточкам хранится в браузере.

- Теория и порядок испытания по лабораторному практикуму НИТУ «МИСиС», с. 25–33
- Интерактивный копёр, разметка диаграммы и калькулятор
- Обработка данных из тетради с указанием читаемости и условных величин
- Два графика температурной серии и карточки для самопроверки
